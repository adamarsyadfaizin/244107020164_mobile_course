## Struktur repository

Folder `01-week-1-...` sampai `16-week-16-...` menyimpan deliverable tiap minggu. Setiap `.gitignore` mingguan hanya mengizinkan folder tugas seperti `lib/`, `test/`, `docs/`, `screenshots/`, `coverage/`, atau folder khusus yang tercantum pada struktur mata kuliah. Project Flutter lengkap tetap tersedia secara lokal untuk menjalankan aplikasi, tetapi boilerplate platform, cache build, dan dependency hasil generate tidak dimasukkan ke Git.

Ringkasan portofolio tambahan tersedia di [portfolio-summary.md](portfolio-summary.md).
